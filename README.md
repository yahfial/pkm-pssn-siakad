# Simulasi Phishing SIAKAD PKM PSSN

Simulasi halaman login SIAKAD PPI Curug untuk edukasi keamanan siber.
Bagian dari Program Kreativitas Mahasiswa Pengabdian kepada Masyarakat (PKM-PM/PKM PSSN).

## File

| File | Fungsi |
|------|--------|
| `login.html` | Halaman login clone SIAKAD |
| `login.php` | Credential capture + redirect |
| `index.php` | Entry point + IP logging |
| `ip.php` | IP/User-Agent logger |
| `dashboard.php` | Dashboard monitoring real-time |
| `*.jpg / *.png` | Asset gambar (logo, background) |

## Cara Pakai

`Bash
cd <folder-ini>
php -S 0.0.0.0:8080
`

Buka `http://localhost:8080` di browser.
